# raw/ — materiali grezzi del progetto

Tutto ciò che serve come riferimento, senza essere necessariamente la
versione "in produzione" (quella è in `src/` alla radice del progetto).

- **`codice/`** — copia del codice attuale del sito (html, css, js), così
  com'è ora.
- **`immagini/`** — logo, immagine hero, immagine di sfondo delle card, più
  un mockup di riferimento (biglietti da visita/materiali coordinati) non
  usato direttamente nel sito ma tenuto come riferimento grafico.
- **`font/`** — nota su quali font usa il sito e da dove vengono caricati
  (nessun file `.woff`/`.ttf` locale al momento).
- **`testi/`** — il testo di ogni pagina estratto in un file `.md`
  separato, nell'ordine in cui appare, per rileggerlo/modificarlo senza
  dover cercare tra i tag HTML.
- **`screenshot/`** — anteprime visive generate finora durante il lavoro
  sullo stile (header, hero, pagina intera).

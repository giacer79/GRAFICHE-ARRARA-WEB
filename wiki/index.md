# Wiki — Grafiche Arrara

Indice della documentazione viva del progetto. Legge questo file prima
di lavorare al codice (dopo `CLAUDE.md`), poi apri le pagine rilevanti
per il compito da svolgere.

| Pagina | Contenuto |
|---|---|
| [`project-overview.md`](./project-overview.md) | Cos'è il progetto, obiettivi, stato attuale, come si lavora |
| [`brand.md`](./brand.md) | Identità di Grafiche Arrara: storia, servizi, contatti, logo |
| [`visual-style.md`](./visual-style.md) | Stile grafico **definitivo**: palette, tipografia, motivo dell'angolo tagliato — da rispettare |
| [`site-architecture.md`](./site-architecture.md) | Struttura file, stack tecnico, navigazione tra le pagine |
| [`pages.md`](./pages.md) | Dettaglio di ogni pagina: sezioni, contenuto, stato (placeholder o definitivo) |
| [`components.md`](./components.md) | Elementi riutilizzabili: header, card, hero, footer, form, mappa |
| [`animation-system.md`](./animation-system.md) | Tutte le animazioni/interazioni e la logica dietro ciascuna |
| [`code-review.md`](./code-review.md) | Stato tecnico del codice: cosa è stato ripulito, problemi noti, debito tecnico |
| [`improvement-plan.md`](./improvement-plan.md) | Prossimi step consigliati, in ordine di priorità — aggiornare prima di modifiche rilevanti |
| [`seo-strategy.md`](./seo-strategy.md) | Mappa ricerche, regole editoriali, metadati, immagini e misurazione SEO |
| [`log.md`](./log.md) | Cronologia di tutte le operazioni/decisioni fatte finora |

## Come orientarsi rapidamente
- Devi capire **cosa fa/rappresenta** il sito → `project-overview.md` +
  `brand.md`
- Devi modificare **stile/colori/font** → `visual-style.md` (leggi prima
  di toccare `style.css`)
- Devi modificare **una pagina specifica** → `pages.md` +
  `site-architecture.md`
- Devi aggiungere/modificare **un componente** (card, header, form...)
  → `components.md`
- Devi lavorare su **hover/animazioni** → `animation-system.md`
- Devi capire **se qualcosa è già rotto o incompleto** →
  `code-review.md`
- Devi decidere **cosa fare dopo** → `improvement-plan.md`
- Devi modificare **testi, metadati o indicizzazione** → `seo-strategy.md`
- Vuoi sapere **cosa è già stato fatto/deciso** → `log.md`
